# Tijay Le – Professional GitHub Pages Site

This folder contains a complete one-page professional website ready for GitHub Pages.

## Files
- `index.html` – main website
- `styles.css` – visual styling and responsive design
- `profile.jpg` – professional headshot

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. For a personal site, name the repository `YOUR-USERNAME.github.io`.
3. Upload `index.html`, `styles.css`, and `profile.jpg` to the root of the repository.
4. Open the repository's **Settings**.
5. Select **Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then save.
8. GitHub will provide the public site address after deployment.

You can edit the text directly inside `index.html`.
